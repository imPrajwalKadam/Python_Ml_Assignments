There is one dataset of wine which classify the wines according to its contents into three classes 
consider below wine dataset  as "WinePredictor.csv"

This data are result of chemical analysis of wine growth in the same region in italy but derived from three different cultivars.
The analysis determined  the quantities of 13 constitueants found in each of three  types of wines.

Wine dataset contains 13 features as
1. Alcohol
2. Malic Acid
3. Ash
4. Alcalinity of ash
5. Magnesium	
6. Total phenols
7. Flavanoids
8. Nonflavanoid phenols
9. Proanthocyanins
10. Color intensity
11. Hue	
12. OD280/OD315 of diluted wines
13.	Proline
  According to the above features wine can be classified as 
  - Class 1
  - Class 2
  - class 3
