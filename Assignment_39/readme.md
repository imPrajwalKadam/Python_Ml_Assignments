Machine Learning : Dataset Description - Student Performance ML
Dataset
the dataset student_performance_ml.csv contains acadamic and behavioral information of student. The objective of 
this dataset is to predict whether a student will pass(1) or Fail (0)  based on various input features.

Each row in the dataset represents one student, and each column represent a measerable factor that may influence 
academic performance.

Features description
- studyHours - number of hours a student studies per day.
- Attandance - percentage of  class attandance.
- PreviousScore - Marks obtained in the previous examination.
- AssignmentsCompleted - Number of assignments compilted by the students.
- SleepHours - Average number of hours the student sleep per day.
- finalResult - TargetVariable(output)
    - 1 -> Pass
    - 0 ->Fail

Objective of the dataset
The goal is to:
- Analyze how different factors affacts student performance .
- Build a machine learning model to predict whether a student will pass or fail
- understand concepts such a training ,testing ,accuracy, confusion matrix, overfitting n and model evaluation.
