Automated Platform Surveillance System


This system is periodic system monitoring  + logging automation tool.
At a fixed time interval(Example :every 5 minute), it automatically call

1 . Create a follder (if not already present).
2 . Creates a new log file with timestamp.
3 . Writes a system report into the log .
- CPU Usage
- Ram Usage
- Disk Usage for all partitions.
- network sent/recive status.

4 Write A Process Report:
- PID , Process Name ,username,stateus
- Process Start time
- CPU % and memory % per process

5 repeat this forever until u dont stop it ctrl+c
